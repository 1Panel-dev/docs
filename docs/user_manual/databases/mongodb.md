# MongoDB

!!! info "适用版本与权限"
    MongoDB 管理适用于社区版、专业版和企业版。企业版普通用户需要数据库查看或管理权限。

!!! note ""
    1Panel 在 **数据库 -> MongoDB** 中管理应用商店安装的 MongoDB 和远程 MongoDB 实例，并管理实例中的数据库、用户、权限和备份。

## 1 管理实例

### 1.1 本地实例

!!! note ""
    点击实例选择器中的 **安装 MongoDB**，可跳转到应用商店完成安装。安装完成后，页面会显示本地实例状态，并提供连接信息、从服务器同步和 Mongo Express 等入口。

### 1.2 远程实例

!!! note ""
    进入 **远程数据库**，点击 **创建远程数据库**，填写以下参数：

    - **名称**：1Panel 中用于识别该连接的名称；
    - **版本**：当前页面可选择 `6.x`、`7.x` 或 `8.x`；
    - **地址、端口**：MongoDB 服务地址和端口，默认端口为 `27017`；
    - **初始数据库**：用于认证的数据库，默认值为 `admin`；
    - **用户名、密码**：远程实例凭据；
    - **超时时间、描述**：连接超时和备注。

!!! note ""
    保存前必须先点击 **连接测试**。解绑远程实例只会删除 1Panel 中的连接信息，不会删除远程 MongoDB 数据。

## 2 创建数据库

!!! note ""
    选择目标实例后点击 **创建数据库**，填写数据库名、用户名、密码、权限和描述。当前页面提供以下权限：

    - `dbOwner`：数据库所有者；
    - `read`：只读；
    - `readWrite`：读写；
    - `userAdmin`：用户管理。

## 3 数据库操作

!!! note ""
    列表支持修改密码、调整权限、查看备份、导入备份和删除数据库。数据库被外部删除后，页面会标记异常状态；可以使用 **从服务器同步** 更新 1Panel 中的记录。

!!! warning "删除与恢复"
    删除数据库或在恢复前清空集合会直接影响业务数据。操作前应确认备份可用，并核对当前选择的 MongoDB 实例。

## 4 连接和 Web 管理

!!! note ""
    **连接信息** 会根据本地容器、主机和远程访问场景给出不同地址。Mongo Express 仅用于本地实例；未安装时页面会引导前往应用商店安装。
