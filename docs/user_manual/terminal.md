## 1 Terminal Management

!!! note ""
    Go to **Host → Terminal** to open the terminal page.
    The terminal connects to the local server by default; connection fails if local login credentials are not set.

    - Supports connecting to existing hosts (configured in **Terminal → Hosts**) or new hosts
    - Supports reconnect
    - Supports multiple local server tabs
    - Supports fullscreen mode
    - Supports quick commands (predefined in **Terminal → Quick Commands**)
    - Supports batch input across all active connections
