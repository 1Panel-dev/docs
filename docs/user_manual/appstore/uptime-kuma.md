# 使用 1Panel 可视化安装 Uptime Kuma

!!! note ""
    **Uptime Kuma** 是一款开源的服务器监控和状态检测工具，它帮助您跟踪服务器的可用性、性能和健康状态。

## 1. 打开应用商店

!!! note ""
    进入 1Panel 控制台后，点击左侧菜单的 **「应用商店」**。

<div class="browser-mockup" markdown>

![image-20251016110510084](../../img/app/appstores.png)

</div>

## 2. 搜索 Uptime Kuma 并安装

!!! note ""
    在右上角搜索框输入 **Uptime Kuma**，点击应用卡片进入详情页，选择 **安装**。

<div class="browser-mockup" markdown>

![image-20251021163433091](../../img/app/uptime-kuma.png)

</div>

## 3. 配置安装参数

!!! note ""
     你可以根据需要配置

    - **名称** (输入框内可自定义应用名称，默认为 uptime-kuma)
    - **版本** (下拉选择所需的 Uptime Kuma 版本)
    - **端口** (应用的访问端口，默认为 3001)
    - **端口外部访问** (开启后，将允许从外部网络访问此应用端口)

    确认设置无误后，点击 **确认** 按钮开始安装。

<div class="browser-mockup" markdown>

![image-20251021163633965](../../img/app/uptime-kuma_install.png)

</div>

!!! note ""
     等待安装完成即可

## 4. 访问 Uptime Kuma 服务

!!! note ""
     安装完成后，确认 1Panel 配置默认访问地址，已配置过可忽略

<div class="browser-mockup" markdown>

![image-20251016172322315](../../img/app/setting_ip.png)

</div>

!!! note ""
     返回应用商店，点击 **跳转** 即可访问 Uptime Kuma 服务

<div class="browser-mockup" markdown>

![image-20251021163916064](../../img/app/uptime-kuma_jump.png)

</div>

!!! note ""
     创建管理员账户即可使用

<div class="browser-mockup" markdown>

![image-20251021163947718](../../img/app/uptime-kuma_view.png)

</div>
