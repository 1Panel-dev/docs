# Install DataEase Visually Using 1Panel

!!! note ""
    **DataEase** is an open‑source BI tool that helps users quickly analyze data and identify business trends, enabling business improvement and optimization. DataEase supports a wide range of data sources, allows rapid chart creation via drag‑and‑drop, and supports easy sharing with others.

## 1. Open the App Store

!!! note ""
    After entering the 1Panel console, click **App Store** in the left menu.

![image-20251016110510084](../../img/app/appstores.png)
{: .original}

## 2. Search for DataEase and Install

!!! note ""
    Enter **DataEase** in the search box in the upper right corner, click the application card to go to the details page, then select **Install**.

![image-20251021164523104](../../img/app/dataease.png)
{: .original}

## 3. Configure Installation Parameters

!!! note ""
    You can configure the following as needed:

    - **Name**: Customize the application name (default: dataease)
    - **Version**: Select the desired DataEase version from the dropdown
    - **Database Service**: Select the database service for data storage, such as MySQL
    - **Database Name**: Name of the database created for the application
    - **Database User**: Username for database connection
    - **Database User Password**: Password for the database user
    - **Administrator**: Set the administrator account for DataEase
    - **Default Administrator Password**: Set the initial password for the DataEase administrator
    - **Port**: Access port for the application (default: 8080)
    - **Port External Access**: When enabled, allows external network access to the application port

    After confirming the settings are correct, click the **Confirm** button to start installation.

![image-20251021164616512](../../img/app/dataease_install.png)
{: .original}

!!! note ""
    Wait for the installation to complete.

## 4. Access the DataEase Service

!!! note ""
    After installation, confirm the default access address in 1Panel. Skip this step if already configured.

![image-20251016172322315](../../img/app/setting_ip.png)
{: .original}

!!! note ""
    Return to the App Store and click **Jump** to access the DataEase service.

![image-20251021164804606](../../img/app/dataease_jump.png)
{: .original}

!!! note ""
    Log in with the default credentials: Username `admin`, Password `DataEase@123456`.

![image-20251021165236307](../../img/app/dataease_view.png)
{: .original}
