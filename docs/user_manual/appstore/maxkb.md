# Install MaxKB Visually Using 1Panel

!!! note ""
    **MaxKB** = Max Knowledge Brain, is a powerful and easy-to-use enterprise-grade agent platform. It supports RAG (Retrieval-Augmented Generation), workflow orchestration, and MCP tool calling. MaxKB can integrate with all mainstream large language models, and is widely used in intelligent customer service, enterprise internal knowledge base Q&A, employee assistants, academic research, education, and other scenarios.

## 1. Open the App Store

!!! note ""
    After entering the 1Panel console, click **App Store** in the left menu.

![image-20251016110510084](../../img/app/appstores.png)
{: .original}

## 2. Search for MaxKB and Install

!!! note ""
    Enter **MaxKB** in the search box in the upper right corner, click the application card to go to the details page, then select **Install**.

![image-20251021152126077](../../img/app/maxkb.png)
{: .original}

## 3. Configure Installation Parameters

!!! note ""
    You can configure the following as needed:

    - **Name**: Customize the application name (default: maxkb)
    - **Version**: Select the desired MaxKB version from the dropdown
    - **Port**: Access port for the application (default: 8080)
    - **Port External Access**: When enabled, allows external network access to the application port

    After confirming the settings are correct, click the **Confirm** button to start installation.

![image-20251021152214757](../../img/app/maxkb_install.png)
{: .original}

!!! note ""
    Wait for the installation to complete.

## 4. Access the MaxKB Service

!!! note ""
    After installation, confirm the default access address in 1Panel. Skip this step if already configured.

![image-20251016172322315](../../img/app/setting_ip.png)
{: .original}

!!! note ""
    Return to the App Store and click **Jump** to access the MaxKB service.

![image-20251021152816361](../../img/app/maxkb_jump.png)
{: .original}

!!! note ""
    Log in with the default credentials: Username `admin`, Password `MaxKB@123..`.

![image-20251021152859104](../../img/app/maxkb_view.png)
{: .original}
