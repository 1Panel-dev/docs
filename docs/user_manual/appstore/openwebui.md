# 使用 1Panel 可视化安装 Open WebUI

!!! note ""
     **Open WebUI** 是针对 LLM 用户友好的 WebUI，支持的 LLM 运行程序包括 Ollama、OpenAI 兼容的 API。

## 1. 打开应用商店

!!! note ""
    进入 1Panel 控制台后，点击左侧菜单的 **「应用商店」**。

<div class="browser-mockup" markdown>

![image-20251016110510084](../../img/app/appstores.png)

</div>

## 2. 搜索 Open WebUI 并安装

!!! note ""
    在右上角搜索框输入 **Open WebUI**，点击应用卡片进入详情页，选择 **安装**。

<div class="browser-mockup" markdown>

![image-20251021175502686](../../img/app/open-webui.png)

</div>

## 3. 配置安装参数

!!! note ""
     你可以根据需要配置

    - **名称** (输入框内可自定义应用名称，默认为 ollama-webui)
    - **版本** (下拉选择所需的 OpenWebUI 版本)
    - **端口** (应用的访问端口，默认为 3000)
    - **Ollama 服务地址** (填入已安装的 Ollama 服务的内网地址)
    - **Secret Key** (设置用于 OpenWebUI 的安全密钥)
    - **端口外部访问** (开启后，将允许从外部网络访问此应用端口)

    确认设置无误后，点击 **确认** 按钮开始安装。

<div class="browser-mockup" markdown>

![image-20251022115250706](../../img/app/open-webui_install.png)

</div>

!!! note ""
     等待安装完成即可

## 4. 访问 Open WebUI 服务

!!! note ""
     安装完成后，确认 1Panel 配置默认访问地址，已配置过可忽略

<div class="browser-mockup" markdown>

![image-20251016172322315](../../img/app/setting_ip.png)

</div>

!!! note ""
     返回应用商店，点击 **跳转** 即可访问 Open WebUI 服务

<div class="browser-mockup" markdown>

![image-20251022114510416](../../img/app/open-webui_jump.png)

</div>
