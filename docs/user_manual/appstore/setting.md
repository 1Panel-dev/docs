# 应用商店设置

!!! note ""
    入口为 **应用商店 -> 设置**。社区版、专业版和企业版均可配置应用安装、升级和卸载的默认行为；自定义应用仓库配置需要专业版或企业版许可证。

## 1 默认操作

- **卸载时删除备份**：启用后，卸载应用时默认同时删除该应用在本地保存的备份。
- **卸载时删除镜像**：启用后，卸载应用时默认清理对应镜像。仍被其他容器使用的镜像可能无法删除。
- **升级前备份**：启用后，升级应用前默认创建备份，用于失败回滚或手动恢复。
- **升级后删除旧镜像**：启用后，升级完成后清理旧版本镜像。
- **安装时放行端口**：启用后，应用安装时默认在主机防火墙中放行配置的外部端口。

![应用商店设置](../../img/app/appstore_setting.png)

!!! warning "默认值会影响后续任务"
    这些选项会作为后续安装、升级或卸载操作的默认值。执行具体任务前仍应检查确认框，尤其是备份、镜像清理和端口放行选项。

## 2 自定义应用仓库

专业版和企业版可在本页配置节点使用的自定义应用仓库。启用前应确认仓库地址、分支和访问凭证有效，并只使用可信仓库；仓库内容可以定义容器镜像、挂载和启动参数。
