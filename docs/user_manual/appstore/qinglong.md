# 使用 1Panel 可视化安装 青龙

!!! note ""
     **青龙** 是一个支持 Python3、JavaScript、Shell、Typescript 的定时任务管理平台。

## 1. 打开应用商店

!!! note ""
    进入 1Panel 控制台后，点击左侧菜单的 **「应用商店」**。

![image-20251016110510084](../../img/app/appstores.png)

## 2. 搜索 青龙 并安装

!!! note ""
    在右上角搜索框输入 **青龙**，点击应用卡片进入详情页，选择 **安装**。

![image-20251021144136110](../../img/app/qinglong.png)

## 3. 配置安装参数

!!! note ""
     你可以根据需要配置

    - **名称** (输入框内可自定义应用名称，默认为 qinglong)
    - **版本** (下拉选择所需的青龙版本)
    - **网页端口** (WebUI 的访问端口，默认为 5700)
    - **端口外部访问** (开启后，将允许从外部网络访问此应用端口)
    
    确认设置无误后，点击 **确认** 按钮开始安装。

![image-20251021144226976](../../img/app/qinglong_install.png)

!!! note ""
     等待安装完成即可

## 4. 配置访问 青龙 服务

!!! note ""
     安装完成后，确认 1Panel 配置默认访问地址，已配置过可忽略

![image-20251016172322315](../../img/app/setting_ip.png)

!!! note ""
     返回应用商店，点击 **跳转** 即可访问 青龙 服务

![image-20251021144529508](../../img/app/qinglong_jump.png)

!!! note ""
     配置初始化信息即可使用

![image-20251021144603548](../../img/app/qinglong_view.png)
