# 使用 1Panel 可视化安装 Home Assistant

!!! note ""
    **Home Assistant** 是一款智能家居自动化平台，提供了丰富的功能和灵活性，用于控制和自动化您家中的各种智能设备和服务。

## 1. 打开应用商店

!!! note ""
    进入 1Panel 控制台后，点击左侧菜单的 **「应用商店」**。

![image-20251016110510084](../../img/app/appstore_white.png)

## 2. 搜索 Home Assistant 并安装

!!! note ""
    在右上角搜索框输入 **Home Assistant**，点击应用卡片进入详情页，选择 **安装**。

![image-20251021134434601](../../img/app/home-assistant.png)

## 3. 配置安装参数

!!! note ""
     你可以根据需要配置

    - **名称** (输入框内可自定义应用名称，默认为 home-assistant)
    - **版本** (下拉选择所需的 Home Assistant 版本)
    - **端口** (应用的访问端口，默认为 8123)
    - **时区** (设置容器运行时区，默认为 Asia/Shanghai)

    确认设置无误后，点击 **确认** 按钮开始安装。

![image-20251021134531378](../../img/app/home-assistant_install.png)

!!! note ""
     等待安装完成即可

## 4. 配置访问 Home Assistant 服务

!!! note ""
     安装完成后，确认 1Panel 配置默认访问地址，已配置过可忽略

![image-20251016172322315](../../img/app/setting_ip.png)

!!! note ""
     返回应用商店，点击 **跳转** 即可访问 Home Assistant 服务

![image-20251021135110250](../../img/app/home-assistant_jump.png)

!!! note ""
     完成初始化配置即可使用

![image-20251021135328234](../../img/app/home-assistant_view.png)
