# Install LobeChat Visually Using 1Panel

!!! note ""
    **LobeChat** is a modern open‑source chat application and development framework for ChatGPT/LLMs. It supports speech synthesis, multi‑modal interaction, and an extensible plugin system (function call). With one click, you can deploy your own private ChatGPT/Gemini/Claude/Ollama application for free.

## 1. Open the App Store

!!! note ""
    After entering the 1Panel console, click **App Store** in the left menu.

![image-20251016110510084](../../img/app/appstores.png)
{: .original}

## 2. Search for LobeChat and Install

!!! note ""
    Enter **LobeChat** in the search box in the upper right corner, click the application card to go to the details page, then select **Install**.

![image-20251022201953880](../../img/app/lobechat.png)
{: .original}

## 3. Configure Installation Parameters

!!! note ""
    You can configure the following as needed:

    - **Name**: Customize the application name (default: lobe-chat)
    - **Version**: Select the desired LobeChat version from the dropdown
    - **Port**: Access port for the application (default: 40247)
    - **OpenAI API Key**: Enter your OpenAI API key
    - **OpenAI Proxy URL**: Set the proxy address for API requests (default: official endpoint)
    - **Access Password**: Set the access password for the LobeChat interface
    - **OpenAI Model List**: Configure available models (optional)
    - **Port External Access**: When enabled, allows external network access to the application port

    After confirming the settings are correct, click the **Confirm** button to start installation.

![image-20251022202302786](../../img/app/lobechat_install.png)
{: .original}

!!! note ""
    Wait for the installation to complete.

## 4. Access the LobeChat Service

!!! note ""
    After installation, confirm the default access address in 1Panel. Skip this step if already configured.

![image-20251016172322315](../../img/app/setting_ip.png)
{: .original}

!!! note ""
    Return to the App Store and click **Jump** to access the LobeChat service.

![image-20251022202628790](../../img/app/lobechat_jump.png)
{: .original}

!!! note ""
    You can now use the service.

![image-20251022202721850](../../img/app/lobechat_view.png)
{: .original}
