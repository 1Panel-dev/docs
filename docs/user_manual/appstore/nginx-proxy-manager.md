# Install Nginx Proxy Manager Visually Using 1Panel

!!! note ""
    **Nginx Proxy Manager** is a powerful reverse proxy and web server management tool that allows you to easily manage proxy settings for multiple websites and applications.

## 1. Open the App Store

!!! note ""
    After entering the 1Panel console, click **App Store** in the left menu.

![image-20251016110510084](../../img/app/appstores.png)
{: .original}

## 2. Search for Nginx Proxy Manager and Install

!!! note ""
    Enter **Nginx Proxy Manager** in the search box in the upper right corner, click the application card to go to the details page, then select **Install**.

![image-20251020152016138](../../img/app/nginx_proxy_manager.png)
{: .original}

## 3. Configure Installation Parameters

!!! note ""
    You can configure the following as needed:

    - **Name**: Customize the application name (default: nginx-proxy-manager)
    - **Version**: Select the desired Nginx Proxy Manager version from the dropdown
    - **HTTP Port**: Access port for HTTP service (default: 30080)
    - **Console Port**: Access port for the WebUI management interface (default: 30081)
    - **HTTPS Port**: Access port for HTTPS service (default: 30443)
    - **Port External Access**: When enabled, allows external network access to the application ports

    After confirming the settings are correct, click the **Confirm** button to start installation.

![image-20251020151917440](../../img/app/nginx_proxy_manager_install.png)
{: .original}

!!! note ""
    Wait for the installation to complete.

## 4. Access the Nginx Proxy Manager Service

!!! note ""
    After installation, confirm the default access address in 1Panel. Skip this step if already configured.

![image-20251016172322315](../../img/app/setting_ip.png)
{: .original}

!!! note ""
    Return to the App Store and click **Jump** to access the Nginx Proxy Manager service.

![image-20251020152901371](../../img/app/nginx_proxy_manager_jump.png)
{: .original}

!!! note ""
    Log in with the default credentials: Username `admin@example.com`, Password `changeme`.

![image-20251020153112135](../../img/app/nginx_proxy_manager_view.png)
{: .original}
