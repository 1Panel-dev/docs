# 安全运维报表

!!! info "适用版本与权限"
    安全运维报表仅在 1Panel 企业版中可用，需要有效企业版许可证和报表查看或管理权限。

!!! note ""
    进入 **安全运维报表**，可以按节点汇总系统、登录、网站、资源、计划任务和告警数据，并生成历史报表。

## 1 报表内容
!!! note ""
    - **概览**：汇总评分、风险和主要运行指标；
    - **系统**：展示主机和系统运行情况；
    - **登录**：分析登录事件和异常；
    - **网站**：汇总网站状态及相关风险；
    - **资源**：展示 CPU、内存、磁盘等资源情况；
    - **计划任务**：统计任务执行和失败记录；
    - **告警**：汇总告警事件；
    - **历史**：查看已经生成的报表；
    - **设置**：配置导出格式、保存路径、自动导出和系统阈值，并查看最近生成结果。

## 2 选择节点

!!! note ""
    报表按当前选择的节点加载数据。切换节点后，各标签会重新初始化；导出或保存前应确认报表节点和统计时间范围。

## 3 生成与导出

!!! note ""
    在页面选择统计范围并刷新数据，确认内容完整后生成或导出报表。历史页面用于追溯已经保存的结果，实时页面数据变化不会自动改写既有历史报表。

## 4 报表设置

!!! note ""
    设置页用于配置默认导出格式、保存路径、自动导出和系统阈值，也可以立即生成报表。自动导出启用后，系统按页面提示的时间生成报表；修改系统阈值会影响后续报表中的资源风险判断。

!!! note "数据边界"
    报表基于 1Panel 当前可采集的数据生成，用于运维检查和趋势分析，不等同于外部合规认证或完整的安全审计结论。
