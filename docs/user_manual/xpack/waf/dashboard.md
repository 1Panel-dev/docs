# WAF 首页

!!! info "版本说明"
    首页中的请求统计、拦截地图和趋势图仅在专业版和企业版中可用，需要有效许可证。企业版普通用户需要 WAF 查看权限；通过首页开关启用防护还需要 WAF 管理权限。

!!! note "页面内容"
    首页展示今日请求数、拦截数、4xx 和 5xx 状态数量，以及请求来源地图、请求趋势和拦截趋势。WAF 未开启时，专业版和企业版用户可以通过页面顶部的开关启用全局防护。

    社区版进入首页时会看到版本能力说明，可以继续使用 **黑白名单**、**网站设置** 和 **全局设置**。社区版需要在 **全局设置** 中操作 WAF 总开关。
!!! note ""
    页面无统计数据时，依次检查 OpenResty 状态、WAF 总开关、网站 WAF 开关、网站是否产生请求，以及当前查询节点是否正确。关闭总开关会使所有网站失去 WAF 防护，但不会自动删除已配置的规则。
