# WAF 封锁记录

!!! info "版本说明"
    封锁记录仅在专业版和企业版中可用，需要有效许可证。企业版普通用户需要 WAF 查看权限；解封、清空、导出和加入黑名单需要 WAF 管理权限。

!!! note "记录与操作"
    封锁记录展示被频率限制等规则临时封锁的 IP，包括封锁状态、封锁时间、IP 归属地和命中规则。可以按 IP 搜索，并查看触发封锁的请求详情。

    页面支持解除封锁、将记录中的 IP 或 IP 段加入长期黑名单、批量处理选中记录、导出封锁记录和清空记录。解除封锁只影响当前状态，如果触发条件仍然存在，该 IP 可能再次被封锁。

!!! warning "临时封锁"
    临时封锁信息保存在 OpenResty 中，重启 OpenResty 会解除临时封锁。需要持续阻止某个来源时，可以将其加入 IP 黑名单；操作前应确认该地址不是 CDN 出口、共享代理或正常用户地址。
