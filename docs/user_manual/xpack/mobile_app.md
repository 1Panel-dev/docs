# 移动端

!!! info "适用版本与权限"
    移动端仅在专业版和企业版中可用，需要有效许可证，并且仅管理员或具备受保护角色的账号可操作。

!!! note ""
    进入 **高级功能 -> 移动端**，可以生成用于 1Panel 移动端 App 绑定面板的二维码。

## 1 绑定前提
!!! note ""
    - 移动设备可以访问当前面板地址；
    - 面板地址、端口、HTTPS 和安全入口配置正确；
    - 如开启授权 IP、域名绑定或防火墙限制，已允许移动设备访问；
    - 当前账号已启用 API 接口，并配置 API Key、IP 白名单和接口密钥有效期。

## 2 生成二维码

!!! note ""
    页面根据面板别名和当前访问地址生成绑定二维码，二维码中的临时令牌有效期为 1 分钟。请使用移动端 App 在倒计时结束前完成扫描。

!!! warning "安全提示"
    绑定二维码和 API Key 都属于敏感凭据。二维码过期后应重新生成。

## 3 API 接口配置
!!! note ""
    移动端绑定依赖当前账号的 API 接口设置：

    - **API Key**：移动端请求凭据；
    - **IP 白名单**：限制允许调用 API 的来源地址或网段；
    - **接口密钥有效期**：校验接口请求时间戳与当前时间的间隔，单位为分钟；设置为 `0` 时不校验请求时间戳。该设置不会让 API Key 自动失效；如需撤销访问，应重置 API Key 或禁用 API 接口；
    - **API 接口状态**：禁用后，已绑定客户端无法继续调用。
