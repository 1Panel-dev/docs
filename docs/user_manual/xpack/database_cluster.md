# 数据库集群

!!! info "适用版本与权限"
    数据库集群仅在专业版和企业版中可用，需要有效许可证、节点管理能力和数据库集群权限。

!!! note ""
    进入 **高级功能 -> 数据库集群**，可以管理 MySQL、PostgreSQL 和 Redis 的主从部署。页面按数据库类型提供独立标签。

## 1 使用前提

- 已在节点管理中添加并检查目标节点；
- 源节点和目标节点之间网络互通；
- 应用商店可用，目标节点具备足够磁盘和内存；
- 数据库端口未被占用，防火墙策略允许集群内部通信；
- 已完成业务数据备份。

## 2 创建集群

1. 选择 MySQL、PostgreSQL 或 Redis 标签。
2. 点击 **添加集群**，填写集群名称。
3. 选择安装节点并配置主节点参数。
4. 提交任务并在任务日志中确认安装完成。
5. 在已有集群中添加从节点，等待初始化和复制状态正常。

## 3 日常管理

!!! note ""
    页面展示集群节点、角色、状态和复制信息，并支持同步状态、添加节点和删除节点。删除集群节点时，页面会检查关联的应用安装；是否同时删除应用和数据以确认对话框为准。

!!! warning "故障切换"
    数据库复制状态正常不等同于已经具备自动故障切换能力。执行主从切换、删除主节点或恢复备份前，应先确认业务连接方式、复制延迟和回滚方案。
