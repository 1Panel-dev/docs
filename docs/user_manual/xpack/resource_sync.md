# 资源同步

!!! info "适用版本与权限"
    资源同步仅在专业版和企业版中可用，需要有效许可证，并且仅管理员或受保护角色可操作。使用前需至少存在两个可用节点。

!!! note ""
    进入 **高级功能 -> 资源同步**，可以在节点之间同步文件、容器镜像、应用和证书。

## 1 文件对传

!!! note ""
    文件对传页左右两侧分别选择节点，浏览目录后可通过方向按钮双向传输单个文件或目录。参与传输的节点均需安装 `rsync` 组件；提交后可在任务日志查看进度。

## 2 镜像对传

!!! note ""
    选择源节点上的一个或多个容器镜像，再选择目标节点。提交前页面会汇总镜像数、节点数和任务数。同步前应确认目标节点磁盘空间以及镜像架构是否兼容。

## 3 应用对传

!!! note ""
    应用对传用于把源节点上的一个已安装应用复制到一个或多个目标节点。仅支持无资源依赖，或依赖 MySQL、MariaDB、PostgreSQL 数据库的应用；不支持 OpenResty、Redis、MongoDB 及其他不受支持的资源依赖。存在数据库依赖时，应按页面提示配置目标数据库映射。

    对传过程中会备份并恢复应用配置和数据。执行前应停止写入或安排维护窗口，并确认目标节点没有名称、端口和目录冲突。

## 4 证书同步

!!! note ""
    证书同步用于把证书资源推送到其他节点。同步完成后，如目标网站需要使用该证书，还需要在目标节点的网站 HTTPS 配置中完成绑定或替换。

!!! warning "覆盖风险"
    资源同步会在目标节点创建或覆盖数据。提交任务前应核对源节点、目标节点、资源名称和目标路径，并为重要数据保留独立备份。
