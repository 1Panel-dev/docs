# 界面设置

!!! info "适用版本与权限"
    界面设置仅在专业版和企业版中可用，需要有效许可证，并且仅管理员可操作。

!!! note ""
    进入 **高级功能 -> 界面设置**，可以配置面板品牌和登录页外观。

## 1 品牌配置

- **带文字 Logo**：用于展开状态下的导航区域；
- **Logo**：用于收起状态或其他紧凑区域；
- **Favicon**：浏览器标签页图标。

## 2 登录页配置

!!! note ""
    登录背景支持图片或颜色，并可配置登录按钮和链接颜色。上传图片前应控制尺寸和文件大小，避免影响登录页加载速度。

## 3 保存与恢复

!!! note ""
    点击 **保存** 应用当前配置；点击 **恢复默认** 清除自定义品牌。更新后浏览器可能继续使用缓存的 Logo 或 Favicon，可强制刷新后再次确认。

!!! note "与面板设置的关系"
    **面板设置 -> 面板** 提供主题、菜单标签页、水印和面板名称等通用设置；本页主要管理专业版和企业版的品牌资源与登录页样式。
