## 1 Create Golang Runtime Environment

!!! note ""
    Click the **Create Runtime Environment** button and select the Golang version, runtime directory, and other information.
    - Currently supported versions: Golang 1.21, 1.22, 1.23, and 1.24. Choose the appropriate version based on your needs.

![runtime_golang_create.png](../../img/websites/runtime_golang_create.png)
{: .browser-mockup}

## 2 Manage Golang Runtime Environment

!!! note ""
    - On the list page, you can perform the following operations on the Golang runtime environment: stop, start, restart, edit, delete, and view logs.

![runtime_golang_list.png](../../img/websites/runtime_golang_list.png)
