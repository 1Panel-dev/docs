## 1 Upload Certificate

!!! note ""
    Click the **Upload Certificate** button above the certificate list.
    You can upload your existing SSL certificate to 1Panel for HTTPS access on websites.

![img.png](../../img/websites/certificate_upload.png)
{: .browser-mockup}

!!! note ""
    When uploading a certificate, you must provide the **certificate file** and **private key file**, both in **PEM format**.

    Certificate and private key files must use PEM format.
