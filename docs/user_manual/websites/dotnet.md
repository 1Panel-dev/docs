## 1 Create .NET Runtime Environment

!!! note ""
    Click the **Create Runtime Environment** button and select the .NET version, runtime directory, and other information.

    - Currently supported versions: .NET 9.0, 8.0, and 6.0. Choose the appropriate version based on your needs.
    - The `mcr.microsoft.com/dotnet/aspnet` image is used. You need to compile your code into a `.dll` file first, then place it in the runtime directory.

![runtime_net_create.png](../../img/websites/runtime_net_create.png)

## 2 Manage .NET Runtime Environment

!!! note ""
    - On the list page, you can perform the following operations on the .NET runtime environment: stop, start, restart, edit, delete, and view logs.

![runtime_net_list.png](../../img/websites/runtime_net_list.png)
