## 1 Logs

!!! note ""
    The website log viewer in 1Panel supports the following operations:

    - View access logs and error logs
    - Enable/disable logging
    - Track logs in real time
    - Download log files
    - Clear log contents

![img.png](../../img/websites/log.png)
{: .browser-mockup}

## 2 Configuration Files

!!! note ""
    - View and modify the OpenResty configuration for the target website
    - Websites using PHP runtime also support editing FPM and PHP configuration files

![img.png](../../img/websites/web_openresty.png)

## 3 Default Site

!!! note ""
    The Set Default Site feature allows you to route unmatched domain requests to a specified default website.

![img.png](../../img/websites/website_default.png)
{: .browser-mockup}

## 4 Default Pages

!!! note ""
    The Set Default Pages feature allows you to customize the content of the following default pages:
    
    - **Website 404 Error Page**
    - **Website Not Found Page**
    - **Static Website Default Page**
    - **PHP Website Default Page**
    - **Website Suspended Page**

![img.png](../../img/websites/website_default_page.png)
{: .browser-mockup}

## 5 Start / Stop Website

!!! note ""
    Click **Running** or **Stopped** in the list to toggle the website status.

![img.png](../../img/websites/website_start.png)

## 6 Set Expiration Time

!!! note ""
    After setting an expiration time for a website, the system will automatically stop the site upon expiration for efficient resource management.

![img.png](../../img/websites/web_expire.png)
{: .browser-mockup}

## 7 Delete Website

!!! note ""
    You can delete a website via the **More** menu in the website list.

    - **Force Delete**: Skip errors during deletion and perform the operation directly
    - **Delete App**: Remove associated 1Panel applications when deleting the website
    - **Delete Backups**: Delete the website and all its backup files at the same time

![img.png](../../img/websites/website_del.png)
{: .browser-mockup}
