## 1 What is OpenClaw?

!!! note ""
    OpenClaw is a personal AI assistant that runs on your own devices.
    It can chat with you across a wide range of communication platforms you already use, including: Feishu, DingTalk, WeCom, QQ, WhatsApp, Telegram, Slack, Discord, Google Chat, Signal, iMessage, Microsoft Teams, WebChat, and more.

    If you want a personal AI assistant that runs locally 24/7, this is it.

## 2 How to install OpenClaw in 1Panel?

!!! note ""
    OpenClaw is available in the 1Panel App Store.
    Go to the App Store page and deploy it quickly via **one‑click installation** ([one‑click installation](../user_manual/appstore/openclaw.md)).

## How to run local models with Ollama?

!!! note ""
    OpenClaw supports connecting to Ollama local large models.
    You can chat and run inference locally without relying on cloud tokens, balancing privacy and cost.

    To learn more about integrating OpenClaw with Ollama, please refer to:
    [OpenClaw Integration with Ollama Local Models](https://openclaw.club/quick-start).
