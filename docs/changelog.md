## 1 版本说明

!!! note ""
    **版本号说明：*- 像其它优秀开源项目一样，1Panel 将保持每月发布一个新的功能版本，功能版本中如遇较为紧急或严重的 Bug，将及时推出 Bug 修复的小版本。  
    **1Panel 版本号命名规则为：*- v 大版本.功能版本. Bug 修复版本，示例如下：

    - v2.0.1 是 v2.0.0 之后的 Bug 修复版本
    - v2.1.0 是 v2.0.0 之后的功能版本

## 2 更新内容

### v2.0.0

2025年6月10日

## ✨ 亮点更新

- **新增多机管理能力**
  一台主机可以统一管理多台子节点，轻松实现跨服务器的资源调度与集中管理

- **支持自定义仓库，离线环境也能安装应用**
  用户可以自定义应用和镜像仓库，有效解决离线环境下的应用安装问题，部署更加灵活

- **新增文件对传功能**
  基于 `rsync` 并通过 SSH 密钥方式，实现不同服务器间的高速文件传输，操作高效安全

- **网站管理功能全面重构**
  - 支持创建 `子网站` 类型
  - 创建网站时支持一键开启 HTTPS、关联数据库等
  - 网站设置新增真实 IP 配置、网站类型切换、数据库切换等功能

- **新增网站负载均衡功能**
  提供可视化配置方式，帮助网站构建高可用架构，显著提升稳定性与访问性能

- **新增脚本库功能**
  支持集中管理工具箱中的各类应用安装脚本，可以上传自定义脚本，并在创建 Shell 类型计划任务时直接调用

- **容器页面重构**
  - 新增容器概览页，实时展示运行状态与资源使用情况
  - 创建容器时支持更多参数配置
  - 支持通过命令创建容器，适配多样化需求

- **快照机制重构**
  全新快照功能支持多策略设置，数据备份更灵活，管理更高效

## 📋 完整更新列表

- 新增 **任务管理功能**，统一管理应用、网站等任务，全面提升任务执行效率
- **WAF 性能优化**，防护机制更高效智能
- 运行环境支持自定义 **端口、环境变量、Volume 挂载**
- **OpenResty** 支持 HTTP/3 协议
- 安装 OpenResty 时支持自定义网站目录，适配多种使用场景
- 多个 PHP 网站可以共用同一个 PHP 容器，资源占用更低
- PHP 运行环境支持开启 **Supervisor 进程守护**
- PHP 运行环境支持扩展管理
- **备份账号机制升级**
  - 新增支持谷歌云盘、阿里云盘、又拍云等多种云盘
  - 支持创建多个同类型账号，管理更灵活高效
- 概览页支持自定义显示的应用卡片，聚焦核心服务信息
- 支持隐藏左侧菜单栏，界面更简洁
- **主机终端重构**
  - 默认使用 SSH 密钥登录本机
  - 支持字体、光标、滚动等终端设置
- 支持自定义登录页面的图片和背景色，打造个性化面板风格
- 更多功能细节优化，进一步提升用户体验与操作便捷性
- **修复了若干已知问题**，增强系统稳定性
