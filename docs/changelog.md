## 1 版本说明

!!! note ""
    **版本号说明：*- 像其它优秀开源项目一样，1Panel 将保持每月发布一个新的功能版本，功能版本中如遇较为紧急或严重的 Bug，将及时推出 Bug 修复的小版本。  
    **1Panel 版本号命名规则为：*- v 大版本.功能版本. Bug 修复版本，示例如下：

    - v2.0.1 是 v2.0.0 之后的 Bug 修复版本
    - v2.1.0 是 v2.0.0 之后的功能版本

### v2.0.0

2025年6月10日

## ✨ 亮点更新

- **新增多机管理能力**
  一台主机可以统一管理多台子节点，轻松实现跨服务器的资源调度与集中管理

- **支持自定义仓库，离线环境也能安装应用**
  用户可以自定义应用和镜像仓库，有效解决离线环境下的应用安装问题，部署更加灵活

- **新增文件对传功能**
  基于 `rsync` 并通过 SSH 密钥方式，实现不同服务器间的高速文件传输，操作高效安全

- **网站管理功能全面重构**
  - 支持创建 `子网站` 类型
  - 创建网站时支持一键开启 HTTPS、关联数据库等
  - 网站设置新增真实 IP 配置、网站类型切换、数据库切换等功能

- **新增网站负载均衡功能**
  提供可视化配置方式，帮助网站构建高可用架构，显著提升稳定性与访问性能

- **新增脚本库功能**
  支持集中管理工具箱中的各类应用安装脚本，可以上传自定义脚本，并在创建 Shell 类型计划任务时直接调用

- **容器页面重构**
  - 新增容器概览页，实时展示运行状态与资源使用情况
  - 创建容器时支持更多参数配置
  - 支持通过命令创建容器，适配多样化需求

- **快照机制重构**
  全新快照功能支持多策略设置，数据备份更灵活，管理更高效
