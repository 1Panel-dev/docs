## 2 更新内容

### v2.2.5

2026年8月7日

!!! note "新增功能"

    * 【AI 网关】新增视觉增强功能
    * 【AI 网关】API Key 支持设置有效期
    * 【AI 网关】调用日志新增上游耗时展示
    * 【AI 网关】新增 API 协议互转功能
    * 【AI 网关】新增文生图 API 支持
    * 【用户管理】新增 OIDC 与 SAML 2.0 登录认证支持
    * 【用户管理】新增 LDAP 登录认证与相关配置功能
    * 【运维报表】新增报表快照与运行记录管理功能
    * 【虚拟机】支持同步已有虚拟机
    * 【虚拟机】创建虚拟机时支持快速创建镜像、网络和存储资源
    * 【面板设置】支持企业版离线试用
    * 【面板设置】支持从企业版恢复至社区版

!!! note "功能优化"

    * 【AI 网关】优化敏感词命中后的响应格式
    * 【AI 网关】优化智能路由判断逻辑
    * 【AI 网关】优化服务状态栏展示
    * 【AI 网关】优化模型账号修改后的适配逻辑
    * 【AI 网关】优化模型账号不可用状态的判断逻辑
    * 【Skills Hub】优化技能版本操作按钮
    * 【运维报表】优化网站监控与 WAF 状态判断逻辑
    * 【面板设置】支持从社区版迁移至企业版时保留管理员账号信息

!!! note "问题修复"

    * 【AI 网关】修复了部分场景下设置保存失败的问题
    * 【用户管理】修复了只读角色无法正常访问部分功能的问题
    * 【用户管理】修复了部分接口权限规则缺失的问题
    * 【运维报表】修复了磁盘状态显示与风险等级不一致的问题
    * 【虚拟机】修复了 ARM64 环境下虚拟机健康检查异常的问题
