## 2 更新内容

### v2.3.0

2026年9月14日

!!! note "新增功能"

    * 【应用商店】安装包内置应用商店离线包
    * 【AI 网关】账号调度支持多级并发控制与请求排队
    * 【AI 网关】新增 Embeddings 向量接口支持
    * 【AI 网关】账号池支持为同一模型账号配置多个 API 类型
    * 【AI 网关】上游请求失败时支持自动切换账号与候选模型
    * 【AI 网关】智能路由支持自定义调用模型名称
    * 【虚拟机管理】创建虚拟机时支持选择操作系统并自动匹配磁盘总线类型
    * 【界面设置】支持自定义底部导航链接与显示状态

!!! note "功能优化"

    * 【AI 网关】账号池列表支持自定义显示列
    * 【AI 网关】优化概览页并发状态与调用统计展示
    * 【AI 网关】优化视觉增强的图片内容提取与数量限制
    * 【AI 网关】优化自定义文生图账号的响应格式兼容性
    * 【AI 网关】调用日志支持按时间范围筛选并优化分页展示
    * 【AI 网关】优化 vLLM 消息转发至 DeepSeek 官方 API 的兼容性
    * 【运维报表】优化 PDF 报表导出的字体加载逻辑
    * 【面板设置】完善恢复社区版时的安装包信息与下载提示
    * 【系统】支持 nightly 测试版滚动升级
    * 【系统】完善离线升级的安装包校验与异常处理

!!! note "问题修复"

    * 【防火墙】修复了白名单修改权限校验不完善的问题
    * 【终端】修复了终端会话授权校验与失效处理不完善的问题
    * 【用户管理】修复了防火墙与模型管理等功能权限规则缺失或配置不正确的问题
    * 【虚拟机管理】修复了部分场景下虚拟机数据库字段缺失的问题
    * 【面板设置】修复了上传企业版许可证后未同步至本地节点的问题

### v2.2.5

2026年8月7日

!!! note "新增功能"

    * 【AI 网关】新增视觉增强功能

    * 【AI 网关】优化模型账号不可用状态的判断逻辑
    * 【Skills Hub】优化技能版本操作按钮

    * 【用户管理】修复了部分接口权限规则缺失的问题
