    🎉 **1Panel 离线安装包已集成企业版核心功能。安装完成后，您即可免费体验 7 天企业版全功能；体验期结束后，系统将自动切换至社区版，基础功能不受影响，可继续正常使用。**

## 1 环境要求
   
!!! note ""
    **安装前请确保您的系统符合安装条件：**

    - 操作系统：支持主流 Linux 发行版本（基于 Debian / RedHat，包括国产操作系统）
    - 服务器架构：x86_64、aarch64、armv7l、ppc64le、s390x、riscv64
    - 内存要求：建议可用内存在 1GB 以上
    - 浏览器要求：请使用 Chrome、Firefox、IE 10+、Edge 等现代浏览器

## 2 下载离线安装包

!!! note ""
    社区版仅提供 x86_64（amd64）架构的离线安装包，请前往 [FIT2CLOUD 开源社区下载页面](https://community.fit2cloud.com/#/products/1panel/downloads) 下载。

## 3 执行安装命令

!!! note ""
    获取对应架构的离线安装包并上传至目标服务器解压。进入解压目录后，执行 install.sh 脚本即可根据提示完成安装。

## 4 升级指南

!!! note ""
    获取对应架构的离线安装包并上传至目标服务器解压。进入解压目录后，执行 upgrade.sh 脚本即可根据提示完成升级。
