!!! note ""
    🎉 **1Panel 离线安装包已集成企业版核心功能。安装完成后，您即可免费体验 7 天企业版全功能；体验期结束后，系统将自动切换至社区版，基础功能不受影响，可继续正常使用。**

## 1 获取离线安装包

!!! note ""
    请根据服务器架构获取对应的离线安装包。

    - **x86_64（amd64）**：请前往 [FIT2CLOUD 开源社区下载页面](https://community.fit2cloud.com/#/products/1panel/downloads) 下载。
    - **aarch64（arm64）**：请填写 [1Panel 企业版试用申请表](https://jsj.top/f/umuYtv) 申请获取安装包。

## 2 安装指南

!!! note ""
    获取对应架构的离线安装包并上传至目标服务器解压。进入解压目录后，执行 install.sh 脚本即可根据提示完成安装。

## 3 升级指南

!!! note ""
    获取对应架构的离线安装包并上传至目标服务器解压。进入解压目录后，执行 upgrade.sh 脚本即可根据提示完成升级。
